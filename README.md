# Dear-Data

1)Research question

Does the estimated pH of canal water vary across 4 selected locations, based on 100 samples?


2) project overview

My project investigates variations in the pH of canal water across 4 different locations across Hackney - Islington. I chose this topic because I live near a canal, and I've always been concerned about environmental issues and preserving animal habitat.
My aim is to explore whether canal water pH differs between these locations and what these differences might suggest about the water.

I will collect 100 water samples in total, with 25 samples from each of the 4 selected locations. I will be using Universal pH indicator strips and a colour chart to estimate the pH of each sample.
The collected data will be recorded in a dataset, analysed using Microsoft Excel and be used to create graphs. Finally, the data will be visualised using a Processing sketch.

3) objectives of the project
   - record 100 samples of canal pH observations across 4 locations
   - collect 25 samples from each location
   - estimate the pH of each sample using pH indicator strips and a colour chart
   - organise my observations into a structured dataset
   - use Excel to calculate mean pH values and create 2 different graphs
   - visualise the data on an interactive Processing sketch
  
4) method of data collection
   for each observation, I plan to record:
   - sample_number
   - date of collection
   - site_ID e.g. ABCD
   - pH_reading
  
5) data analysis using Excel
   - used to organise, process and analyse the 100 observations
   - mean pH for each location = sum of pH readings at a location % 25.
     This will produce 4 mean pH values, one for each location
   - I will create 2 graphs in Excel: bar chart, scatter graph of each location
   - the graphs will help me to explore and compare the mean pH between the locations
  
6) data visualisation on Processing (planning)
   The sketch will include:
   - a background image of a canal (roughly)
   - a graph overlaying, which will include all the 100 data points of my samples
   - each sampling location will have a different colour on the graph to distinguish
     which sample is from which location e.g. location one = blue, location two =
     green etc
  - when I hover my mouse above a data point, the samples pH readings, and location and date will appear in a small box above which disappears when mouse is removed from that sample point
